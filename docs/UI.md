# UI Design System (Arena Glass)

- **Themes**: Dark (`#0B1020` → `#141B3A`), Light (`#F4F6FF`), and High-Contrast (`#000000` with crisp white borders), plus customizable accent colors and Big Screen / TV Mode (125% UI scale).
- **Typography**: `Fredoka` display headers, `Nunito` body text, and `JetBrains Mono` with `tabular-nums` for scores, timers, room codes, and ping counters.
- **Colorblind Accessibility**: Every player tank color pairs with a distinct geometric shape emblem (`●`, `■`, `▲`, `◆`, `★`, `⬢`, etc.) across lobby rows, scoreboards, and badges.
- **Responsive Navigation**: Desktop 3-zone top bar + `Ctrl/Cmd+K` Command Palette; mobile/tablet bottom navigation bar and portrait/landscape touch editor.
